# Junteng Liu

Personal homepage for Junteng Liu, a first-year Ph.D. candidate at HKUST NLP Group. Research focuses on natural language processing and machine learning.

This repository is forked from [Academic Pages](https://github.com/academicpages/academicpages.github.io).

## Site content

- `_pages/about.md`: academic background, research interests and skills, research experience, publications, and contact information.
- `_pages/publications.html`: the same six publications listed on the About page.
- `_config.yml`: site identity, author profile, contact links, and deployment settings.

The site navigation contains only About and Publications.
